## 一、先锁死的四条决策

1. **产品形态**：两层共用一套知识图谱。一层是可进阶的教材（路径、概念卡、实验、测验、项目、模板），一层是能指导行动的情报（快讯、早报、周报、深度、过时清单）。
2. **用户不是所有人**。好奇者只做漏斗顶；付费转化打「这周就要用 AI 交差」的产品/运营/开发；高客单打要仓库和对照数据的工程师与小团队。不做学术顶会媒体、荐股、医疗处方。
3. **生产必须人机共创**。常识文可半自动；搭建和应用必须可复现；新闻必须人工选题加事实核验；原理必须引用论文或官方文档。全自动日更长文 = 内容农场，SEO 和信任会一起死。
4. **付费墙卖的不是多几篇文章**，而是路径解锁、判断力、可执行资产、以及「哪篇已经过时」。社群是留存插件，不是主货。

首页主 CTA 不要做成大聊天框，做成：**「测一测你卡在哪一层」**。

品牌先用工作名 **阶见 JieJian**，并列候选：补环、路标、原栈、核稿。先别把时间耗在域名拍卖上。

## 二、你原路径缺的不是四个词，是箭头上的环

「常识 → 搭建 → 应用 → 原理」方向对，但按这四段写课，人会在四个地方掉下去：懂了名词却不会选工具；注册完不知道如何形成工作流；做出 Demo 却不会判断能不能上线；想学原理时没有读论文和发布说明的能力。

所以课程树做成 **8 层主干**，不是 4 个栏目：

| 层 | 名称 | 走完应会什么 | 墙 |
|---|---|---|---|
| L0 | 方向与边界 | AI 能做什么/不能做什么，自己该学哪条岗 | 全文免费 |
| L1 | 常识与工具素养 | 模型 / Token / 幻觉 / 上下文；会评价一次回答 | 全文免费 |
| L2 | 选型与成本 | 云端 vs 本地、产品 vs API、账单估算 | 目录免费，决策表收费 |
| L3 | 搭建 | 最小可运行系统：API、本地模型、入门 RAG、自动化 | 试读约 30% |
| L4 | 工作流与 Agent | 单次对话升级成可重复流程，理解失败恢复 | 会员 |
| L5 | 应用与场景 | 按岗位做出可交差的结果，写得出失败原因 | 结论免费，步骤会员 |
| L6 | 工程化 | 评测、监控、成本、护栏、部署、安全 | 会员 / 专业 |
| L7 | 原理与前沿 | 读懂官方技术报告关键段，判断新在哪 | 会员；源码级走专业档 |

三个最容易劝退的「半层」并进主干，不要另起编号：

- **L1 末 / L2 初**：Prompt 与评价迭代（会聊不会评，是目前中文教程最大断层）
- **L3 末 / L4 初**：把玩具变成能给同事用的东西（权限、版本、回滚）
- **L5 末 / L7 初**：论文/发布 → 三个可执行决策（翻译层，付费差异点）

每一层都由六种零件组成，缺哪种补哪种，而不是再写一篇「全面介绍」：概念卡、动手实验、对照表、常见坑、测验、项目。

横切主题贯穿所有层：**安全合规、失败案例、成本账**。它们不是单独栏目。

## 三、在「AI 知识 + 科技新闻」之外，必须补的品类

只做这两栏，站点会变成杂志，留不住要干活的人。下面这些不是锦上添花，是商业闭环和搜索入口：

1. **工具与模型对照台**：同一任务、同一提示词、同一评测集，记录质量、延迟、价格。这是用户自己做不稳的脏活。
2. **可下载资产库**：提示词包、n8n/Make 工作流、CSV/Notion 对照表、上线检查单、ROI 测算表。订阅如果只有文章，续费率会很难看。
3. **岗位 / 行业 playbook**：把同一条技术路径翻译成产品、运营、开发、教师等任务语言。
4. **评测与失败案例库**：专门收「看起来能跑、实际上不能上线」的案例，这是建立权威最快的方式。
5. **职业与作品集轨道**：哪个项目能放进简历、评审看什么。不是鸡汤。
6. **政策 / 安全 / 合规速读**：只写对产品有什么影响。
7. **实体永久页**：模型、公司、论文、工具各有 URL。文章会过时，实体页是图谱入口。
8. **勘误与变更日志**：公开改错，是反农场的品牌动作。
9. **月度过时清单**：哪些教程作废、替代节点是哪篇。这是续费理由，不是赠品。
10. **站内问答**：只检索本站已审语料，回答必须带段落级引用。语料外就说「还没写过」，记入选题缺口。

情报层不要开成门户。固定五档：快讯（200–400 字）、早报、周报、深度拆解、过时清单。一条快讯如果不能挂到知识节点上，就只是噪音。

竞品空位也在这里：机器之心/量子位快但不体系；通往 AGI 之路有清单和社区，但知识不是要负责的可检索资产；极客时间是死课程；开源路径仓库没有运营和新闻。阶见打的是 **「可进化的中文活教材 + 能指导行动的情报」**。<grok:render card_id="e1db47" card_type="citation_card" type="render_inline_citation"><argument name="citation_id">10</argument></grok:render>

## 四、免费 / 收费怎么切

哲学就三句，顺序不能反：搜索引擎要能读到足够免费层；未付费读者应感到「方法完整、细节被收走了」而不是被骗；已付费读者要说得出续费理由。

**闸门规则**

- 新闻事实免费，判断收费（标题 + 3 点结论公开，影响推演进会员）。
- 路径地图全部可见，节点上锁，锁上写清「差什么前置」。
- 软墙优先：关键表格、代码、对照图模糊；导语、目录、结论公开。不要整页弹窗。
- 注册用户每月 3 篇会员全文（计量试用，也利于 SEO）。
- 普通长文 90 天后可降级免费，制造档案厚度；**实验数据、模板、仓库永不降级**。
- 付费正文必须服务端鉴权。下载用短时 URL + 用户水印。

**定价锚（先上线，再用数据改数字，档位不要超过三档加钩子）**

| 档位 | 价格 | 买到什么 |
|---|---|---|
| 访客 | 0 | 全部免费层；付费文的导语 / 目录 / 结论 |
| 注册 | 0 | 每月 3 篇全文；每日 3 次问答；进度与收藏；邮件 |
| 标准 Pro | ¥39/月 或 ¥328/年 | 路径解锁、P 全文、完整早报周报、基础模板、问答 20 次/日 |
| 专业 Plus | ¥129/月 或 ¥999/年 | 实验仓库、对照原始数据、高阶模板、办公会、问答公平使用 |
| 钩子品 | ¥9.9 周报月卡 / ¥29 单路径 7 天 / ¥99 单资产包 | 验证支付，不破坏年付 |
| 团队 Team | V2，¥99/人/月，5 人起 | 席位、发票、共享进度，不共享账号 |

年付必须明显便宜。学生认证 6 折，要审核。权益用 `entitlements` 表判断，不要在代码里写死套餐名，方便以后拆卖「只买周报」。

收入不要只靠会员：订阅 55–70%，资产单卖 15–25%，联盟和周报赞助各占个位数且必须披露。不做展示广告堆满，不做灰产分销。

开通当天会员必须立刻感到三件事：正在读的 L3 正文展开了；邮箱里出现完整周报历史期；下载中心能带走一份「文档问答上线清单」。如果开通后只是「文章变多了」，转化和续费都会弱。

## 五、整个网站怎么设计：四套站点，不是一个博客主题

导航不超过 7 项：**学习 / 情报 / 工具 / 百科 / 定价 / 搜索 / 登录**。信息架构按「学、看、用」三件事组织，首页是操作系统仪表盘，不是最新文章瀑布。

### 1. 公开站（SEO 主场）

`/` 首页：选路测评 CTA、今日简报 5 条、路径缩略图、工具周榜。  
`/learn` 学习地图可视化；`/learn/[track]/[unit]` 单元容器。  
`/articles/[slug]` 主阅读器。  
`/news` 快讯；`/digest/daily|weekly` 简报着陆。  
`/tools`、`/compare/[pair]`、`/glossary`、`/topics/[cluster]`、`/projects`。  
`/pricing` `/disclosure` `/errata` `/changelog` `/authors/[id]`。  
RSS、sitemap、`llms.txt`。

文章页没有下面这些模块，不允许发布：层徽章与路径坐标（如「L3 搭建 · 文档问答 · 第 4/12」）、Last-verified、导语、目录、墙锚点、结论「读完能做什么」、来源卡、AI 辅助披露、勘误入口、上一课/下一课/相关新闻、JSON-LD。

### 2. 会员应用 `/app`

学习台（断点续学、每日最多 3 个任务）、我的路径、收藏划线笔记、下载中心、Ask、完整简报、Plus 实验室、账单与邀请。

Ask 可以有，但降权。它只答本站已审内容，必须带段落引用；语料外不准编。

### 3. 创作 Studio `/studio`（这个项目真正的产品）

如果 Grok 只存在于有人手敲聊天窗口再粘贴进 CMS，项目就退回成博客。Studio 按内容对象状态机走，不是按「文章列表」：

选题池（趋势 / 图谱缺口 / 失效文）→ Brief（层、读者、必引源、禁止项）→ 生成台（多版本、温度、模型路由、本篇成本）→ 事实清单核验台（每条声明：通过 / 存疑 / 删除，未处理完不能提审）→ 编辑器（人机 diff、墙锚点、内链建议）→ 审校队列 → 发布检查单 → 过期刷新。

### 4. 管理后台 `/admin`

用户封禁、权益补发、订单退款、DAG 维护、提示词版本、模型成本看板、SEO 重定向、操作日志、功能开关。财务权限和内容权限拆开。

分发层不要做成主站：邮件、公众号、即刻/掘金/小红书卡片、会员私有 RSS。V1 不做 App、不做小程序写作后台、不做大广场社区。

## 六、五条用户路径（只优化这些）

- **P1 学**：SEO 概念卡 → 注册领测评 → 免费走完 L0–L1 → 卡在 L2 墙 → Pro  
- **P2 报**：快讯/早报 → 邮箱 → 连续 7 天打开 → 周报完整版墙 → Pro  
- **P3 做**：岗位测评 → 个性化路径 → 单元测验 → 项目课单卖或升 Plus  
- **P4 深**：Plus → 仓库/对照台 → Ask 带引用 → 提交勘误 → 成为贡献者  
- **P5 内**：缺口雷达 → Brief → Grok 起草 → 事实核验 → 终审 → 发布 → 7/30/90 天回写  

权限硬规则：发布按钮只给 Publisher；Author 禁止自发布，包括快讯；新闻必须 FactChecker 签字；事实清单未 100% 处理不能提审。

## 七、Grok 流水线：状态机，不是「让机器人更新首页」

状态：`idea → assigned → researching → drafting → factcheck → editing → legal(按需) → scheduled → published → needs_update → archived`

按类型分流，SLA 写死：

- **快讯**：材料包 → Grok 压成 200–400 字 + 3 点结论 + 候选节点 → 编辑 3 分钟核验。事件后 2 小时。Grok 只做压缩，不做独家判断。
- **概念卡**：图谱缺口出题 → 按「定义 / 类比 / 反例 / 前置 / 下一步」模板生成 → 事实清单 → 终审。48 小时。
- **路径单元**：编辑先写学习目标和练习 → Grok 按节展开 → 工程师抽检代码 → 终审。
- **深度**：人选题 → 多源材料包 → Grok 起草 → 对抗式核验（假设每句都错）→ **判断段必须人重写**。
- **周报**：快讯归并 → 三栏草稿（重要 / 不重要 / 被高估）→ 主编改判断。

强制字段缺一不可才能发布：`title, slug, level, node_ids, sources, ai_assist_ratio, model_used, factcheck_status, reviewer_id, last_verified_at, expires_at, paywall_tier, changelog`。

红线：医疗/法律/投资建议默认拒写；未核验数字和「第一/唯一」拦截；代码必须跑通或标明「未运行」；新闻必须双源或官方一手。输出走 CMS JSON schema，禁止直接吐 HTML。每次生成写 `generation_log`（模型、prompt 哈希、tokens、成本、检索到的文档）。

文风：具体、可证伪、先判断再解释。禁用「在当今快速发展的人工智能时代」。判断段是付费墙后真正值钱的部分，也是最不能自动化的部分。

## 九、分阶段：功能可以砍，路径不能空

**0–3 月 MVP**  
只打透一条路径：**从 0 做一个文档问答**（同时覆盖产品、运营、开发）。20+ 概念卡，日更快讯，周报一期都不缺，登录 + 计量墙 + 标准会员支付，Studio 最小闭环。  
Plus、对照台、Ask、社区、App 全部不做。  
成功标准：邮件列表约 2,000；付费 50–100；能回答「路径和周报哪个更转化」。

这条路径建议 9–12 个节点，例如：做/不做决策 → 四个词先够用 → 密钥账单隐私 → 选栈决策树（结论公开，分支表上锁）→ 20 条验收问题 → 切片 → 第一次检索失败长什么样 → 引用绑回原文 → 10 问盲测 → 权限日志限额 → 何时不该上 Agent → 失败复盘包。

**3–9 月 V1**  
3 条路径、工具雷达、模板商店、语义搜索、过期扫描、Ask、Plus 与资产包、公众号分发。目标付费 500–1,500，年付占比 >40%。

**9–18 月 V2**  
对照实验台、团队席位、英文摘要层、企业简报试点、贡献者机制。国内镜像视访问需求再定。

阶段闸门：第 6 周如果没人自愿学完第 3 单元，改路径设计而不是加栏目；第 16 周如果付费用户说不出续费理由，停止加社群，先把过时清单和资产包做硬。

编辑部可以很小：创始人兼产品 + 主编兼事实核验 + 0.5–1 实验作者 + Grok。真正的大头是主编时间，不是 API 账单。早期模型费用按快讯走便宜快模型，对照台和 Ask 才是成本变量，必须设日预算和降级策略。

北星指标看路径第 4 课到达率、免费到付费 30 日转化、90 日续订、勘误率、Ask 有引用回答占比。不要把 PV 和「本周生成了多少篇」当成功。

## 十、明天就能开工的十件事

1. 锁定定位句和工作名，写一页给作者看的对外说明。  
2. 建 8 层节点表，字段按发布强制项来，先用表格工具也可以。  
3. 写出「文档问答」全部单元的标题、学习目标、墙位置——先不写正文。  
4. 列出 20 张概念卡名单，优先补 L0–L2。  
5. 选定 5 个新闻白名单源，试写 3 条快讯走完整核验。  
6. 文章页线框一张纸画全强制模块，不讨论配色。  
7. Stripe 测试模式 + entitlements 最小实现：免费 / 计量 / Pro。  
8. Studio 最小闭环：材料包 → Grok 出 JSON → 事实清单 → 存成草稿。  
9. 约 5 个目标用户测「你卡在 L2」这种表达是否成立。  
10. 把文档拆进看板：内容 / 产品 / 技术 / 增长四列，只放 MVP。
