Claude Code 从零到精通完全指南

¥29 安理工 2026 班 · 5 折 Agent 工程·更新 2026-09-04·约 18 分钟

Claude Code 是一个在终端里跑的编码代理：你用自然语言说要做什么，它读你的仓库、改文件、跑命令、看结果、再改。和网页聊天最大的区别是——它动的是你真实的项目，做完的东西直接留在磁盘上。

这份指南按「装上 → 第一次对话 → 让它守你的规矩 → 让它替你干重复活」四步走。每一步都有当堂验收：做到哪一步、怎么判断做对了。

一、安装与登录

先确认 Node 版本，再全局安装。安装完成后第一次运行会让你登录，登录方式取决于你用的是订阅账号还是 API Key。

node -v          # 需要 18+
npm i -g @anthropic-ai/claude-code
claude           # 首次运行进入登录

登录成功后会看到一个提示符。此时它还什么都不知道：不知道你的项目、不知道你的习惯。接下来两节就是把这两件事补上。先从项目开始——进入你的仓库目录再启动，它会先扫一遍目录结构，然后等你开口。第一次对话建议从「总结这个仓库」开始，看它理解得对不对，再决定给多大权限……
