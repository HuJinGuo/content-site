实时预览

Claude Code 是一个在终端里跑的编码代理：你用自然语言说要做什么，它读你的仓库、改文件、跑命令、看结果、再改。

这份指南按「装上 → 第一次对话 → 让它守你的规矩 → 让它替你干重复活」四步走。

一、安装与登录

先确认 Node 版本，再全局安装。

node -v
npm i -g @anthropic-ai/claude-code
claude

登录成功后会看到一个提示符。此时它还什么都不知道……
