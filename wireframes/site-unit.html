学完你能：在自己电脑上，从一个文件夹跑起一个能提问、能给出处的最小项目；说出它哪一步最容易出错。

先说结论：最小 RAG 只有四步——切分、向量化、检索、拼提示词。这一课不讲原理（第 9 课讲），只让它跑起来。

1 · 环境与前置

你需要 Python 3.12、一个文件夹里 20 篇左右的 Markdown、一个模型 API Key（任一家兼容接口）。没有 Key 的话本课末尾有本地模型替代方案。

2 · 切分与向量化

切分粒度是这一课最容易翻车的地方：太碎失去上下文，太大检索不准。先用 500 字 + 50 字重叠。

常见失败：把整篇文章当一块 → 检索永远命中同一篇。修法：看第 3 步的 top_k 与块长关系表。
