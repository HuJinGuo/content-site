### 2.3 开关的工程语义

- 服务端求值，每次请求读内存快照（TTL 30s），改开关不需要部署。
- 每个开关有：说明、负责人、各阶段默认值、依赖（`ads.direct` 依赖 `ads.enabled`）、前置条件清单（能自动算的自动算，见第 11 节）、回滚说明。
- 改动写审计日志（谁、何时、从什么到什么、备注）。
- 总开关关闭是**杀开关**：TTL 内全站生效；已排期数据保留；有广告主时自动发通知邮件。
- 开关只控「渲染与路由」，不删数据；迁移随 MVP 一起上，开的时候不需要发版。
- 前端不自行判断开关；一切由服务端渲染结果决定（避免关了还闪一下）。

## 5. 逐模块推导

每个模块：**任务 → 页面 → 关键交互 → 状态 → 数据 → 埋点 → 验收 → 开关影响**。

### 5.1 首页

- 任务：三秒明白「这是一张 AI 知识地图 + 每天的情报」，一步进入自己的位置。
- 结构（自上而下）：品牌 + 一句话 → 主 CTA「测一测你卡在哪一层」/ 登录态「从这里继续」 → 今日简报 5 条（每条层徽章 + 3 点里的第 1 点）→ 路径缩略（8 层横条，已发布节点实心、规划中空心）→ 精选 3（featured 卡）→ R1 → 最新概念卡 6 → 工具目录入口（本周更新的 3 个实体）→ 页脚（订阅、编辑方针、披露、勘误、RSS）。
- 交互：路径缩略可横向点到层；简报条点进快讯；无聊天框。
- 状态：登录 / 未登录两版 hero；无今日简报（节假日）显示「最近一期」；骨架加载。
- 数据：issues(daily 最新)、content_nodes(featured, latest concept)、entities(recent)、用户 progress。
- 埋点：`home_cta_assess`、`home_cta_continue`、`home_digest_click`、`home_r1_click(kind)`。
- 验收：首屏 HTML 含简报文字（SSR）；未登录首屏无任何需要登录的动作；移动端 hero + 简报在一屏内。
- 开关：R1 内容变化；`ads.self_serve.jobs` 开后加「招聘精选 3」区块。

### 5.2 选路测评 `/assess`

- 任务：2 分钟内得到「你在第几层、从哪一单元开始、先不要学什么」。
- 四题（单选，逐题一屏，可返回）：
  1. 目标：搞懂概念 / 提效办公学习 / 搭知识库或自动化 / 写代码做产品 / 理解原理
  2. 现状：没用过 / 用过对话产品 / 用过 API 或编码代理 / 在做生产系统
  3. 每周时间：< 2h / 2–5h / > 5h
  4. 岗位：学生 / 产品运营 / 开发 / 管理 / 其他
- 映射（规则表，可在 Studio 改）：现状定起点层（没用过 → L0；对话产品 → L1；API / 代理 → L3；生产系统 → L5），目标定路径（知识库 → doc-qa；办公 → workflow-basics（V1）；代码 → engineer-eval（V1）；原理 → L7 读本），时间定每日任务数（1 / 2 / 3），岗位定领域列与示例语言。MVP 只有 doc-qa 一条路径时，其他目标给「这条路径也覆盖你的目标的 N 个单元 + 先读这些概念卡」，不假装有别的路径。
- 结果页：层徽章大字 + 一句解释 + 推荐路径卡（起始单元、预计时长）+ 「先不要学什么」3 条 + 「先读 3 张概念卡」+ 分享卡 + 「保存结果」（匿名存 localStorage，登录后合并）。
- 状态：中途退出保留答案 7 天；重测覆盖并记录历史。
- 数据：assessments(user_id nullable, answers, level, track, unit, at)。
- 埋点：`assess_start`、`assess_step(n)`、`assess_complete(level, track)`、`assess_share`、`assess_to_unit`。
- 验收：完成率（start → complete）初值 ≥ 60%；结果页到首单元点击 ≥ 40%；5 个真人测试接受「你卡在 L2」的表达。
- 开关：无。

### 5.3 学习地图 `/learn`

- 任务：一眼看全体系，知道哪些已写、哪些在路上、自己走到哪。
- 桌面：8 行（层）× 6 列（领域）网格；每格显示节点数与状态点（已发布实心 / 规划中空心 / 有更新金点 / 已过时灰点）；行首层名 + 一句话；列首领域名。点格 → 抽屉列出节点。顶部筛选：层、领域、岗位、只看已发布、只看我未读（登录）。
- 移动：层手风琴，每层内按领域分组。
- **不做硬锁**：内容全免费，任何节点可直接读；前置未读只显示「建议先读 X」标签（原则 1、5）。
- 规划中节点可点「想看」（+1），是缺口探测的读者信号；显示计数不显示排名。
- 登录态叠加：已读 / 已读完 / 收藏。
- 状态：空格显示「这一格还没写，想看 +1」；全部规划中的层（V1 前的 L6）显示层说明与最近的替代阅读。

### 5.4 路径页与单元页

### 5.5 阅读器 `/articles/[slug]`（所有长文共用）

- 任务：读完知道能做什么、信不信、下一步去哪。
- 模块顺序（附录 A of `04`，此处定交互）：
  - 顶部 2px 金色进度线（`01`）。
  - 坐标条：层徽章（中性 chip「L3 · 搭建」，不做八色）· 路径坐标 · 面包屑。
  - 标题（宋体）· 元信息（作者 / 时长 / 发布 / **Last-verified** / 版本）。
  - **信任条**（折叠，一行）：「AI 辅助撰写 · 核验 himma · 来源 6 · 实测 macOS 15 2026-09-12 · 最近核实 3 天前」，点开显示披露全文。
  - 「读完你能…」1–3 条可观察动词。
  - 目录（桌面右栏 sticky；移动折叠）。
  - 导语（解决什么、不解决什么）。
  - 正文：callout 四种（要点 / 注意 / 失败案例 / 成本账，后三者对应横切模块，图标 + 左侧线，不用彩色底）；代码块带复制与**实测徽章**（「实测通过 · 环境 · 日期」或「未运行」），点徽章展开实测记录摘要；术语首次出现下划虚线，桌面悬停卡、移动点开底部抽屉；图有说明；表格可横滑。
  - 结论 → 练习 / 下一步 → 来源卡（chip 分级：官方 / 论文 / 二手 / 社媒，悬停显示出版方与日期；可点）→ AI 披露（固定文案，不可关）→ 勘误与变更（折叠 changelog；有勘误时文首另有红条）→ 相关节点与相关快讯 → R3 → 工具条：收藏 · 划线 · 复制引用（带 URL 与 Last-verified）· 分享卡 · 三键反馈 · 报告错误 · 赞赏（`tipping.enabled`）。
- 划线：选中文本 → 浮条「划线 / 复制引用 / 报告此处错误 / 没看懂这段」；划线存到 `/app/library`（登录）。
- 阅读设置：字号三档、宽度两档、深浅色，存本地。
- 状态：
  - 正常；
  - **可能过时**（now > review_by）：文首黄条「最近核实于 X，可能已过时。查看本月过时清单」；
  - **已作废**（archived）：红条 + 替代节点链接，正文保留可读；
  - **有勘误**：红条摘要 + 链 `/errata`；
  - **自你上次阅读后有更新**（登录，progress.read_at < updated_at）：金点提示 + changelog 高亮；
  - **收费态**（`paywall.enabled` 开 且 access ≠ free 且无权益）：正文在 `<!-- more -->`（缺省前 30%）处服务端截断，其后不进 HTML / JSON；截断处一张**解锁卡**（这篇属于 会员 / 内容码 → 「我有码，去兑」`/redeem` → 「去发卡站买」）；目录完整但截断后条目灰显；来源卡与 AI 披露仍完整显示；列表卡角标「会员」；JSON-LD `isAccessibleForFree: false` + `hasPart`；`group` 专属对无权用户 404。收费态用金色（`04` §6.7），起步态没有任何一篇是收费的；
  - 加载：骨架；错误：卡内红字。
- 移动：右栏消失；目录折叠在标题下；R2 并入 R3；吸底条只在快讯页与首页（订阅早报），文章页不吸底。
- 数据：content_nodes、node_edges、sources、changelog、progress、highlights、feedback。
- 埋点：`article_read_50/90`、`toc_click`、`term_hover`、`code_copy`、`verified_badge_open`、`source_click(tier)`、`feedback(kind)`、`report_error`、`highlight`、`share_card`、`r2_click(kind)`、`r3_click(kind)`。
- 验收：完读率（90%）中位初值 ≥ 30%；三键「有用」占比 ≥ 70%、「过时了」≤ 5%；CLS ≤ 0.1（推荐位固定尺寸预留）；术语悬停不遮正文。
- 开关：R2 / R3；`ask.enabled` 开后侧栏加「问这篇」；`tipping.enabled`；`supporter.enabled` 开后 R3 可出资源包卡；`paywall.enabled` 决定收费态是否存在。

## 6. 内容体验规范（读者看到的内容长什么样）

- **坐标**：每篇顶部必有层徽章与坐标；概念卡只有层，无路径序号。
- **可观察动词**：「读完你能…」用 能画出 / 能算出 / 能上线 / 能判断，不用 了解 / 掌握。
- **过时三态**：正常 / 可能过时（黄）/ 已作废（红 + 替代）。阈值 = `review_by`（评测 30 天、教程 90 天、知识文 180 天、原理 365 天）。
- **来源四级 chip**：官方 / 论文 / 二手 / 社媒；快讯至少双源或官方一手。
- **实测两态**：「实测通过 · 环境 · 日期」/「未运行」。不存在第三态。
- **AI 披露一处**：固定模块，固定文案模板：「本文由 AI 辅助撰写（模型 X，辅助比例约 N%），事实核验：某某，YYYY-MM-DD。发现错误请报告。」
- **横切三块**：安全 / 失败案例 / 成本账 以 callout 出现，可缺省但缺省要在发布检查单里说明原因。
- **术语首次出现**：中文（English）+ 虚线下划 + 悬停卡。
- **数字带日期**：价格、版本、榜单一律「截至 YYYY-MM-DD」。
- **快讯挂接**：每条 1–3 个知识节点，缺则不发。
- **文风**：`04` 第 8.8 节。

## 8. 非功能

- **性能预算**：移动 LCP p75 ≤ 2.5s、CLS ≤ 0.1、INP ≤ 200ms；首屏 HTML ≤ 60KB；标题字体只对 h1/h2 子集化加载，正文系统字体；图片 AVIF/WebP + 尺寸声明；推荐位固定高度。
- **SEO**：SSR；`Article` / `NewsArticle` / `BreadcrumbList` / `FAQPage`（概念卡「常见问题」段）；分区 sitemap；canonical；`llms.txt`；关闭态页面不进 sitemap。
- **可用性**：对比度沿 `01` 已算值；键盘可达；焦点环；术语弹层 aria；`prefers-reduced-motion`；字号可放大到 200% 不破版。
- **隐私**：关闭态无广告相关 cookie；统计用自托管 Umami 无 cookie 模式；问答日志按角色可见；导出 / 删除自助。
- **安全**：权益服务端算；bot 令牌最小权限；上传限类型大小；CSRF；限速；来源即不可信输入（`04` 8.7）。
- **国内访问**：境外起站、暂不备案（用户 2026-09-14 定）；域名 `ai.nornless.com`，Cloudflare 解析，境外 CDN；国内 LCP 以实测为准，静态资源尽量自托管、字体子集化、首屏无第三方；日后若办备案再切国内 CDN。
- **内容许可与抓取**：按 `04` §11「内容许可与抓取政策」执行；`/license` 页公开；`robots.txt` 与 `llms.txt` 同源生成，改政策只改一处。
- **可观测**：每页 Web Vitals 上报；生成任务成本按篇；开关变更审计。

## 9. 编辑部产品（Studio / Admin 的体验也要推导）

- **审稿列表**（快讯、早报）：一屏一条：标题 · 3 点可编辑 · 来源 chip（缺双源红）· 挂接节点选择器（搜索）· 岗位标签；快捷键 J/K 上下、A 通过、E 编辑、R 退回（必填原因）、N 改节点；批量发布；目标 3 分钟 / 条。
- **Brief 表单**：附录 C of `04` 的字段；模板预填；缺必填不能生成。
- **事实清单台**：每条声明一行：原文片段 · 来源链接 · 通过 / 存疑 / 删除 · 备注；未处理数常显；100% 才能提审。
- **编辑器**：左源右预览；人机 diff；插入引用；术语与内链建议侧栏；横切模块缺省提示。
- **选题池**：五信号 + 「想看」计数 + 搜索无结果词，按热度与缺口排序；一键建 brief。
- **覆盖热力图**：8 × 6 网格，色阶 = 已发布 / 规划 / 想看。
- **刷新队列**：到复核日与被快讯触发的文章；显示触发原因；产出 diff 审核。
- **分析**：每篇完读、三键、搜索来源词；早报打开与点击；路径漏斗。
- **开关页**（Admin）：每个开关一行：名称 · 说明 · 当前值 · 阶段默认 · 依赖 · **前置条件清单（自动算的显示实时值与达标状态）** · 最近变更；总开关有二次确认与备注；变更写审计并在 `/changelog` 生成读者可见条目（如「推荐位开始出现赞助卡」）。
- **实体变更审核**：快讯抓到的官方变更 → 候选写入实体页 → 一键确认。
- **认领审核**：官方邮箱验证记录 → 通过 / 拒绝。
